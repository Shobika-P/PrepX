# PrepX — AI Campus Companion

**Analyze. Improve. Prepare.**

PrepX is a web-based academic audit and personalized skill-gap analysis platform that helps students evaluate their academic performance, identify areas for improvement, and understand the skills required for their desired career roles.

🌐 **Live Demo:** https://prep-x-five.vercel.app/  
💻 **GitHub Repository:** https://github.com/Shobika-P/PrepX

## About the Project

PrepX brings academic performance analysis and career-oriented skill-gap identification into one application. It provides students with insights into their academic strengths, attendance, skill deficiencies, and career-development priorities.

## Key Features

- **Student Dashboard** — Centralized overview of academic performance and progress.
- **Academic Audit** — Academic performance and attendance analysis.
- **Skill-Gap Analysis** — Identification of skill deficiencies based on selected career goals.
- **Career Role Selection** — Career-oriented skill requirement analysis.
- **Personalized Recommendations** — Suggested improvement priorities based on analysis.
- **Data Visualization** — Charts and graphs for interpreting academic and skill-related information.
- **Report Generation** — Reports summarizing student analysis.
- **Student Profile and Authentication** — Student data entry and account access.
